## 2024-05-24 - Enhance Input accessibility with proper ARIA associations
**Learning:** Hardcoding or deriving ARIA association IDs from properties like `label` (e.g., `label.toLowerCase().replace(/\s+/g, '-')`) can lead to ID collisions across multiple component instances and Next.js hydration mismatches. Next.js components rendering forms often need dynamic ARIA associations for hints and errors linking to the input element via `aria-describedby` alongside `aria-invalid`.
**Action:** Use React's `useId()` built-in hook to generate robust, unique IDs inside reusable UI form inputs to prevent collisions, ensure screen reader accessibility, and avoid SSR hydration mismatches in Next.js. Update related component tests to assert the semantic relationship (`for` matches `id`) instead of relying on hardcoded literal string IDs.
