## 2024-05-24 - Accessibility improvements for Form Inputs
**Learning:** React's `useId()` is crucial for providing a stable, unique ID for form components (like `Input`) and reliably linking them via ARIA attributes like `aria-describedby` when there are errors or hints. Generating IDs dynamically based on values that can change across components or using regex replacements on optional props (like `label`) can cause conflicts or hydration mismatches, making it difficult for screen readers to correctly announce field-specific error messages.
**Action:** Always use `useId()` as a fallback for form input IDs, and construct associated error and hint IDs (e.g., `${id}-error`) from it. Explicitly link these messages using `aria-invalid={!!error}` and `aria-describedby` pointing to the error or hint element ID.
