## 2024-05-14 - Fix Accessibility Associations via React `useId()`
**Learning:** Found an accessibility issue pattern in the core `Input.tsx` component. The component used label-derived IDs (e.g., lowercase label text with hyphens). This approach led to unintended ID collisions when multiple inputs shared the same label on a page. These collisions prevented screen readers from correctly associating inputs with their specific error messages and hints via `aria-describedby`, because multiple elements ended up sharing the same ID, causing undefined screen reader behavior.
**Action:** Replace label-derived ID generation with React's built-in `useId()` hook to ensure universally unique IDs for every component instance, guaranteeing stable and deterministic associations for `aria-invalid` and `aria-describedby` across all forms.
