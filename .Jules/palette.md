## 2024-10-12 - Proper ARIA Associations and useId() in React
**Learning:** When associating form inputs with error or hint text via `aria-describedby` in React, generating deterministic fallback IDs from strings (like labels) can cause ID collisions and hydration mismatches. Instead, utilizing React's `useId()` generates guaranteed unique, stable IDs across server/client renders. Furthermore, inputs must use `aria-invalid={!!error}` correctly because `@testing-library/react` will render boolean false values as the string `'false'` in the DOM, meaning tests must assert `toHaveAttribute('aria-invalid', 'false')`.
**Action:** Always prefer `useId()` for generating unique ARIA fallback IDs in reusable form components, ensure correct `aria-describedby` linkage to helper/error text IDs, and carefully handle boolean ARIA attribute testing.
