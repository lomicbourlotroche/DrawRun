## 2024-10-30 - W3C Combobox Pattern for Custom Select
**Learning:** Custom UI components like dropdown selects built with `button` and `div` elements must implement the W3C combobox pattern (`role="combobox"`, `role="listbox"`, `role="option"`, `aria-expanded`, `aria-controls`, `aria-selected`) to provide proper context and state information to screen readers. Relying solely on `onClick` and conditional rendering of the dropdown list without these ARIA attributes leaves screen reader users blind to the component's interactive state and available options. Furthermore, when generating unique IDs for React components (e.g. to create unique IDs for `aria-controls`), we must prioritize using React's built-in `useId()` hook over label-derived IDs to prevent ID collisions and hydration mismatches.
**Action:** When implementing custom interactive elements, always consult the W3C ARIA design patterns (like combobox). Specifically, for custom selects:
- Ensure the main trigger button has `role="combobox"`, `aria-expanded`, and `aria-controls`.
- The dropdown container must have `role="listbox"` and an ID generated by `useId()`.
- Each option button must have `role="option"` and `aria-selected` correctly bound to the selected state.
