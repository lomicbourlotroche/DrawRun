## 2024-05-18 - Improved accessibility in Input component
**Learning:** Proper linkage between an input and its associated hint or error messages using `aria-describedby` relies heavily on uniquely generated IDs to avoid collisions, especially when the same input component is rendered multiple times on a single page. Hydration mismatches can occur if `Math.random()` or other non-deterministic ID generation methods are used during server-side rendering (SSR) and client hydration.
**Action:** Always prefer React's `useId()` hook to generate unique IDs for ARIA associations (like `aria-describedby` and `aria-labelledby`) in Next.js or other SSR frameworks. This guarantees true uniqueness across instances and avoids hydration errors. Note that when modifying components that utilize React hooks like `useId()` in the Next.js App Router, ensure the `'use client';` directive is present at the top of the file to prevent Server Component compilation errors.
