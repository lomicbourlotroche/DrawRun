## 2024-07-19 - Input Form ARIA Associations\n**Learning:** In Next.js App Router applications, generating stable IDs for ARIA associations (like `aria-describedby`) is crucial to prevent hydration mismatch errors. A robust pattern for forms is using `React.useId()` to auto-generate a base ID that maps the `<input>` to its corresponding error and hint messages when no explicit ID is provided.\n**Action:** Always prefer `React.useId()` when tying inputs to validation/hint states with `aria-invalid` and `aria-describedby` to ensure robust and accessible form validation without SSR mismatch issues.
