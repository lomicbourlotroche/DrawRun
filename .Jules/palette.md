## 2023-10-27 - Input Component ARIA Association
**Learning:** Proper form accessibility requires explicit associations between the `<input>` element and its corresponding error/hint text, especially when both can be conditionally rendered based on application state. Relying solely on visual proximity (rendering the error message below the input) leaves screen reader users unaware of the validation failure context when they focus the input.
**Action:** When creating reusable form components, automatically generate unique IDs (preferably utilizing React's `useId()` for uniqueness and hydration safety) to construct `errorId` and `hintId`. Use these IDs to set `aria-invalid` and `aria-describedby` on the input element, ensuring assistive technologies correctly announce the context and validation state of the field.
