## 2026-06-18 - Adding aria-labels to icon-only buttons\n**Learning:** The `ThemeToggle` component used a `title` attribute for tooltip functionality but lacked an `aria-label`, which is critical for screen readers encountering icon-only buttons.\n**Action:** Always ensure that any interactive element, especially those relying on icons for visual communication, includes a descriptive `aria-label` attribute even if a `title` is present, to fully support accessibility.
