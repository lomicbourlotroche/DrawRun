## 2024-05-24 - Accessibility improvements for Form Inputs and Selects
**Learning:** Proper association of error and hint messages to form controls (like `Input` and `Select`) using `aria-describedby` provides critical context for screen reader users. Using `useId()` is crucial to generate unique IDs for these associations without risking collisions or hydration mismatches compared to manual string manipulation. Furthermore, inputs should utilize `aria-invalid` to programmatically communicate validation state.

**Action:** When implementing custom form controls (e.g., Input, Select, Textarea), always ensure that error and hint descriptions have unique IDs generated by `useId()` and are linked to the control using `aria-describedby`. Indicate validity state with `aria-invalid={!!error}`.
