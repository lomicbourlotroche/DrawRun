💡 **What**: Added `aria-label` and `aria-pressed` to the password visibility toggle in `LoginForm`.
🎯 **Why**: Icon-only interactive elements need clear context for screen readers. The `aria-pressed` state indicates whether the password is currently shown or hidden.
📸 **Before/After**: Visually identical, but semantically accessible.
♿ **Accessibility**: Enhanced screen reader support for the password toggle button by providing a descriptive label ("Afficher le mot de passe" / "Masquer le mot de passe") and exposing its pressed state.
